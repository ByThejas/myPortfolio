How they came together.

The goal, the approach and where each project stands today.

KAIZEN · PDF toolkit

Goal
One place for everyday file jobs that stays private, fast and simple, processing files locally whenever the workflow allows.
Approach
React and Vite, a locked design system and one reusable tool workspace, so every new tool plugs into the same shell. Built in phases, from foundation and design system to the PDF engine and the tools themselves.
Result
Live and open source (MIT) with 38 tools across Image, PDF and Document categories.

Productivity-116 · Web app

Goal
Turn one long-term goal into daily commitments across a 115-day journey, and make progress visible every day.
Approach
React and Vite with a journey spiral, focus timer, hydration tracking and a daily timeline. All data stays in the browser with local persistence, plus migration and recovery for saved data.
Result
Deployed on Vercel with dark, light and system themes.
Read the code ↗

Grid Bot · Trading automation

Goal
Capture small profits from price swings on BTC/USDT and ETH/USDT without trying to predict direction.
Approach
A grid of orders adjusted by three signals (supply and demand, liquidity, sentiment), with layered risk limits, a daily loss kill switch, a backtester and Telegram alerts.
Result
Validated with a 25-hour continuous run on Binance testnet, ahead of a small real-money canary.
